# Suraj Anand — Software Engineer Portfolio

A modern, high-performance web portfolio built with **React**, **Vite**, and a modular glassmorphic design system. Showcases technical capabilities, enterprise experience, cloud certifications, and full-stack projects.

- **Live Site**: [suraj-anand.github.io/portfolio/](https://suraj-anand.github.io/portfolio/)

## Tech Stack

- **Core**: React 19, Vite, React Router DOM
- **Design System**: Vanilla CSS with cyber-glassmorphic styling, Bootstrap Grid, AOS (Animate on Scroll)
- **Icons & Typography**: React Icons (`react-icons/fa`, `react-icons/si`), Google Fonts (Inter, JetBrains Mono)
- **Deployment**: GitHub Pages / Netlify

## Getting Started

### Prerequisites
- Node.js >= 18.x
- npm >= 9.x

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/suraj-anand/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run start
# or
npm run dev

# Build for production
npm run build
```
